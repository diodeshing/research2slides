# Academic Slide Design

One Slide = One Main Idea. Use a claim-based title that states the conclusion the audience should take away; use a short English technical subtitle when useful.

Prefer a source visual plus focused annotation over bullet-heavy prose. Crop, zoom, highlight, call out, and annotate when these operations preserve the source meaning. Never redraw a result so that values, scales, or uncertainty change.

Every slide spec must define purpose, audience question, main claim, evidence IDs, visual role, takeaway, layout, and speaker notes. Tables should be editable only when parsing is reliable; otherwise use a high-resolution crop with explicit row/column highlighting.

Use generous whitespace, readable type, stable alignment, and a restrained hierarchy. Avoid full-page screenshots, unexplained figures, tiny citations, dense paragraphs, decorative diagrams presented as evidence, and repeated title-only section slides.
