# Paper Reading Mode

Goal: help an audience understand and critically assess someone else's paper.

Use the voice “作者提出 / the authors propose,” not “我们提出.” Build the storyline around Problem -> Background -> Existing Approaches -> Gap -> Core Insight -> Method -> Evidence -> Critical Analysis -> Limitations -> Takeaways.

Give enough background to make the gap intelligible. Separate the paper's claims from the presenter's interpretation. Mark interpretation as analysis and never attach paper-level confidence to an unsupported inference.

Select experiments by the claim they test. Prefer a small number of decisive comparisons and ablations over an exhaustive tour of every table.
