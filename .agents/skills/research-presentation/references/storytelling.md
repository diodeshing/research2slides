# Scientific Storytelling

Plan in presentation units before slides. One unit answers one audience question with one defensible main claim and the evidence needed to understand it.

## Sequence test

Each unit should answer a question created by the preceding unit. A reliable default is:

1. What problem matters?
2. Why do existing approaches fall short?
3. What insight changes the approach?
4. How is the insight implemented?
5. Which evidence validates each important claim?
6. What remains uncertain or limited?
7. What should the audience remember?

Do not fix slide count before counting the information units. Estimate time after planning. If a time budget is later imposed, rank units by narrative necessity and evidence strength, then compress; do not resummarize the source from scratch.

Avoid logic jumps: introduce concepts before formulas, show the method overview before component details, and explain the comparison question before displaying a result table.
