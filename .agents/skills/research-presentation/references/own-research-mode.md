# Own Research Mode

Goal: make the user's contribution, rationale, and evidence legible in a talk about their own work.

Use the voice “我们提出 / we propose” only for material the user identifies as their work. Use Problem -> Motivation -> Gap -> Our Idea -> Contributions -> Method -> Evidence -> Ablation -> Analysis -> Limitations -> Conclusion.

Keep background shorter than in paper-reading mode. Each related-work point must help establish the gap or clarify a design choice. Tie each contribution to evidence; avoid inflated novelty language when comparison evidence is absent.

For defenses and progress reviews, make limitations, incomplete experiments, and future work explicit rather than concealing uncertainty.
